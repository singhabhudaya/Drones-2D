# 🚁 Drone2D: Co-Op Mayhem

A fast-paced 2-player **co-op and versus arena game** made in Python using Pygame.

Pilot neon-lit drones across a futuristic 2D arena. Collect tokens, dodge obstacles, and **outfly your opponent or team up to score high!**

---
## 🎮 Gameplay Preview

![screenshot](screenshots/gameplay.png)

## 🎮 Features

- ✅ Local Co-Op and Versus Modes
- ✅ **Native Keyboard support** (Player 1: WASD, Player 2: Arrow Keys)
- ✅ **Wireless Xbox Controller Support**
- ✅ Real-time drone movement with momentum-based physics
- ✅ Sound effects, music toggle, game UI polish
- ✅ Fun for parties, casual battles, or solo exploration

---

## 🖥️ Platform

- Built for **Windows**
- Runs on **Python 3.9+** with **Pygame**
